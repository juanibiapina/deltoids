# Lazygit

<Note label="Before you start">
  Requires the `deltoids` binary on `PATH`. See [Install](/docs/).
</Note>

## Configuration

Lazygit reads `~/.config/lazygit/config.yml` on macOS and Linux. Add the
`git.paging.pager` key:

```yaml
# ~/.config/lazygit/config.yml
git:
  paging:
    pager: deltoids
```

No `less -R` here: lazygit renders the output in its own panel.

Restart lazygit after saving. The config is read at startup.
