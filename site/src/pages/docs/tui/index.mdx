# Overview

Run `deltoids` in a git repository to open the TUI. `deltoids tui` does
the same. When a diff is piped into `deltoids`, it runs as a
[pager](/docs/integrations/git/) instead.

mouse gestures.

## Panels

The layout follows lazygit. The side panels share the left
column as tabs: the column shows one panel at a time, and its border
lists every tab. The main view on the right shows what the side panel
selects.

| Panel | Shows |
| --- | --- |
| Files | The changed files in the working tree. The tab hides when the tree has no changes and no review is open, and comes back as the current tab when changes appear. |
| Local branches | Your branches and their commits. See [Commits and branches](/docs/tui/history/). |
| Main view | The diff of the selected file, a summary of the selected directory or commit, the log of a branch, or a commit. |

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Next or previous side panel tab |
| `Enter` | Open a file's diff, a branch, or a commit |
| `Esc` | Back out, or close a review |
| `j` / `k` | Move in a list, or between diff lines |
| `Shift+J` / `Shift+K` | Scroll the diff three lines |
| `PgDn` / `PgUp` | Page in the current pane |
| `g` / `G`, `Home` / `End` | Go to the top or bottom of the current pane |
| `o` | Switch a file's diff and its definitions, or a summary and its diffs |
| `q` | Quit |

Select a directory to see a summary of its files: each file's status,
added and removed lines, review tag, and comment count, then the
functions, types, constants, sections, and keys its change touches.
Each shows its signature and what changed: added, removed, renamed,
moved, or its signature, body, docs, comments, or formatting. A file
without definition support lists its hunks instead. Select the first
row of a commit or branch review to see the summary of the whole change.

Press `o` on a file to see its definitions instead of its diff. The
changed ones sit among the unchanged definitions around them, the way a
diff shows context lines: a changed class lists all its methods, and a
long list shows three on each side of each change. Press `o` on a
directory or commit to see every file's diff. Click a row, or press
`Enter` on it in the main view, to open the diff there; an unchanged
definition opens as `z` would show it.

The diff refreshes when files change on disk. The diff keeps its scroll
position when a refresh only changes other files.

## Stage and discard

The Files panel shows each file's status as `git status` does. A file
can have staged and unstaged changes at the same time. Press `s` in the
Files panel, or `Tab` in the diff, to switch between the two.

| Key | Action in the Files panel |
| --- | --- |
| `Space` | Stage or unstage the selected file or directory |
| `a` | Stage or unstage all files |
| `d` | Discard the changes of the selected file or directory |
| `Enter` | Fold or unfold a directory |

In a GitButler workspace, the Files panel shows all uncommitted changes
in one column, and discard goes through `but`. Run `but undo` to get
discarded changes back.

## Hunk context

Each hunk grows to show its enclosing function, class, or section, so you
see where a change sits. deltoids finds these scopes with tree-sitter.
The file header names the file's language, or marks a file whose
language has no scope support.

| Key | Action |
| --- | --- |
| `z` | Expand the hunk under the cursor one scope level, up to the whole file |
| `x` | Shrink it back |

In the Files panel, `z` and `x` act on every hunk of the selected file
or directory.

## Appearance

Press `t` to pick a syntax theme. The diff changes color as soon as you
pick one. Press `<` or `>` to make the sidebar narrower or wider,
or drag the divider. To set a default theme, see
[Configuration](/docs/configuration/#theme).

## Mouse

| Gesture | Action |
| --- | --- |
| Click | Focus the panel under the pointer |
| Click a tab | Show its side panel |
| Click a file | Select it |
| Click `▶` / `▼` | Fold or unfold a directory |
| Click a diff line | Move the cursor there |
| Click a row in a summary or a file's definitions | Open the diff there |
| Double-click a branch or commit | Open it, as `Enter` does |
| Wheel | Scroll the pane under the pointer |
| `Shift` or `Ctrl` + wheel | Step through files |
| Drag the divider | Resize the sidebar |

For the symbol gestures, see [Code navigation](/docs/tui/navigation/).

## Custom commands

You can bind a key to your own shell command, for example to open the
selected file in an editor. See
[Configuration](/docs/configuration/#custom-commands).
